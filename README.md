# Online Quiz System

## Project Overview

The Online Quiz System is a web-based application developed as an academic project. It provides a platform for conducting online quizzes and managing students, questions, quizzes, and results.

The project is developed using Python Flask for the backend, PostgreSQL for database management, and HTML, CSS, and JavaScript for the frontend.

## Technologies Used

- Python
- Flask
- PostgreSQL
- HTML
- CSS
- JavaScript
- Linux Ubuntu

## Features

### Student Module

- Student registration and login
- Access to quizzes
- Attempt online quizzes
- Submit quiz answers
- View quiz results

### Admin Module

- Admin registration and login
- Admin authentication
- Add and manage quiz questions
- Add student information
- Assign quizzes
- Manage quiz data
- View quiz results

## Database

PostgreSQL is used to store and manage application data such as student information, quiz questions, quiz assignments, and quiz results.
